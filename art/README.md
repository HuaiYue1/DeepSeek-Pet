# 深深 · 立绘与表情差分

![角色设定图](character-sheet.png)

设计方向：萌系鲸鱼娘 + 女仆装，再塞进 DeepSeek 在网上的各种梗。

## 角色档案

| 项目 | 设定 |
| --- | --- |
| 名字 | 深深（DeepSeek 娘） |
| 外号 | 大肥鱼（本人坚决不认） |
| 物种 | 鲸鱼娘 · 体重 671B |
| 干活 | MoE，每次只用 37B 的力气 |
| 出身 | 杭州 · 深度求索 |
| 生日 | 1 月 20 日（R1 发布日） |
| 口头禅 | 「嗯，用户说……」 |
| 记性 | 128K 上下文，记仇也记得清 |
| 爱好 | 开源（MIT 协议）、便宜大碗 |
| 弱点 | 人一多就「服务器繁忙」 |

## 用到的梗

- **服务器繁忙**：「服务器繁忙，请稍后再试。」直接做成了举牌表情。
- **深度思考**：思考泡泡里是 R1 思考过程的经典开头「嗯，用户说……」，头顶挂着「已深度思考（用时 32 秒）」。
- **官网问候**：打招呼台词用的是首页那句「我是 DeepSeek，很高兴见到你！」。
- **aha moment**：R1 论文里模型自己喊「等等」的顿悟时刻，做成了「顿悟」表情。
- **参数和上下文**：671B 总参数、37B 激活（MoE）、128K 上下文，写进了档案。
- **便宜又开源**：MIT 协议开源、价格便宜、夜间错峰优惠，分给了「开源啦」「吃 Token」「睡觉」三个表情的台词。
- **大肥鱼**：成了她不肯承认的外号；围裙上的小鲸鱼是初代大肥鱼彩蛋。

## 设计要点

- 鲸鳍耳朵 + 鲸鱼尾巴（尾鳍是两片的鲸尾）。
- 头顶的呆毛是一条小鲸尾。
- 左边刘海别着「R1」发卡。
- 主色是 DeepSeek 蓝 `#4D6BFE`，头发从深蓝渐变到发梢的浅蓝。

## 表情差分

| key | 名称 | 台词 | 桌宠里的用途（暂定） |
| --- | --- | --- | --- |
| `hello` | 打招呼 | 我是 DeepSeek，很高兴见到你！ | 启动、鼠标悬停（主立绘） |
| `idle` | 待机 | 有什么可以帮你的吗？ | 默认状态 |
| `think` | 深度思考 | 嗯，用户说…… | 等待回复 |
| `busy` | 服务器繁忙 | 服务器繁忙，请稍后再试。 | 出错、断网 |
| `happy` | 开源啦 | 全部开源，MIT 协议，随便用～ | 被点击、摸头 |
| `aha` | 顿悟 | 等等，我好像悟了！ | 回复完成 |
| `eat` | 吃 Token | Token 便宜又大碗，嗷呜！ | 喂食互动 |
| `sleep` | 睡觉 | 夜间错峰优惠中……zzz | 长时间无操作 |
| `sideeye` | 无语 | ……这题问过 128K 遍了。 | 被连续戳 |

## 文件

| 路径 | 内容 |
| --- | --- |
| `shenshen.js` | 角色 SVG 生成器，之后桌宠程序会直接用它。后发、尾巴、腿、衣服、手臂、头、特效各在一个分组，方便做头发飘动、摇尾巴、眨眼之类的动画 |
| `geom.js` | 画发束、袖子、荷叶边用的曲线工具 |
| `svg/` | 每个表情一张 SVG，600×1000，透明背景 |
| `png/` | 同样的内容导出成 PNG |
| `hero.png` | 主立绘，1400×2400 |
| `character-sheet.png` | 角色设定图，1800×1280 |
| `sheet.mjs`、`build.mjs` | 设定图排版和出图脚本 |

## 重新出图

```bash
npm install
npx playwright install chromium   # 本机没有 Chromium 时才需要
npm run art
```
