# 深深 · 立绘与表情差分

正式立绘会用 AI 绘图模型出图，风格和参考图保持一致（日系二次元萌系立绘）。流程：

1. 用 [`prompts.md`](prompts.md) 里的提示词出主立绘，再局部重绘脸和手，做出各个表情。
2. 把原图放进 `raw/`，用 `cutout.py` 抠掉背景、统一对齐：

   ```bash
   pip install onnxruntime numpy pillow
   python art/cutout.py art/raw/*.png      # 输出到 art/png/
   ```

3. 加上梗文字（牌子、思考气泡、发卡上的「R1」），重做角色设定图。

`character-sheet.png` 和 `shenshen.js` 是之前的矢量草稿，只用来定角色设定和表情，也可以在正式图到位前给桌宠当占位图。

## 角色档案

| 项目 | 设定 |
| --- | --- |
| 名字 | 深深（DeepSeek 娘） |
| 外号 | 大肥鱼（本人坚决不认） |
| 物种 | 鲸鱼娘 · 体重 671B |
| 干活 | MoE，每次只用 37B 的力气 |
| 出身 | 杭州 · 深度求索 |
| 生日 | 1 月 20 日（R1 发布日） |
| 口头禅 | 「嗯，用户说……」 |
| 记性 | 128K 上下文，记仇也记得清 |
| 爱好 | 开源（MIT 协议）、便宜大碗 |
| 弱点 | 人一多就「服务器繁忙」 |

## 用到的梗

- **服务器繁忙**：「服务器繁忙，请稍后再试。」直接做成了举牌表情。
- **深度思考**：思考泡泡里是 R1 思考过程的经典开头「嗯，用户说……」，头顶挂着「已深度思考（用时 32 秒）」。
- **官网问候**：打招呼台词用的是首页那句「我是 DeepSeek，很高兴见到你！」。
- **aha moment**：R1 论文里模型自己喊「等等」的顿悟时刻，做成了「顿悟」表情。
- **参数和上下文**：671B 总参数、37B 激活（MoE）、128K 上下文，写进了档案。
- **便宜又开源**：MIT 协议开源、价格便宜、夜间错峰优惠，分给了「开源啦」「吃 Token」「睡觉」三个表情的台词。
- **大肥鱼**：成了她不肯承认的外号；围裙上的小鲸鱼是初代大肥鱼彩蛋。

## 设计要点

- 鲸鳍耳朵 + 鲸鱼尾巴（尾鳍是两片的鲸尾）。
- 头顶的呆毛是一条小鲸尾。
- 左边刘海别着「R1」发卡。
- 主色是 DeepSeek 蓝 `#4D6BFE`，头发从深蓝渐变到发梢的浅蓝。

## 表情差分

| key | 名称 | 台词 | 桌宠里的用途（暂定） |
| --- | --- | --- | --- |
| `hello` | 打招呼 | 我是 DeepSeek，很高兴见到你！ | 启动、鼠标悬停（主立绘） |
| `idle` | 待机 | 有什么可以帮你的吗？ | 默认状态 |
| `think` | 深度思考 | 嗯，用户说…… | 等待回复 |
| `busy` | 服务器繁忙 | 服务器繁忙，请稍后再试。 | 出错、断网 |
| `happy` | 开源啦 | 全部开源，MIT 协议，随便用～ | 被点击、摸头 |
| `aha` | 顿悟 | 等等，我好像悟了！ | 回复完成 |
| `eat` | 吃 Token | Token 便宜又大碗，嗷呜！ | 喂食互动 |
| `sleep` | 睡觉 | 夜间错峰优惠中……zzz | 长时间无操作 |
| `sideeye` | 无语 | ……这题问过 128K 遍了。 | 被连续戳 |

## 文件

| 路径 | 内容 |
| --- | --- |
| `prompts.md` | AI 绘图提示词：主立绘（中文、SD/NovelAI 标签、Midjourney 三种写法）和 8 个表情的局部重绘描述 |
| `cutout.py` | 抠图脚本：isnet-anime 模型去背景、去白边，所有表情用同一个裁切框对齐 |
| `shenshen.js`、`geom.js` | 矢量草稿的生成器和曲线工具 |
| `svg/`、`png/` | 矢量草稿导出的 9 个表情（正式图出来后 `png/` 会被替换） |
| `hero.png`、`character-sheet.png` | 矢量草稿的立绘和设定图 |
| `sheet.mjs`、`build.mjs` | 设定图排版和出图脚本 |

## 重新生成矢量草稿

```bash
npm install
npx playwright install chromium   # 本机没有 Chromium 时才需要
npm run art
```
