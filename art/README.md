# 大肥鱼 · 立绘与表情差分

![角色设定图](character-sheet.png)

## 角色档案

| 项目 | 设定 |
| --- | --- |
| 名字 | 大肥鱼 |
| 物种 | 鲸鱼（但坚持说自己是鱼） |
| 代表色 | 深度求索蓝 `#4D6BFE` |
| 性格 | 好奇、话痨，凡事先深度思考 |
| 口头禅 | 「嗯，让我想想……」 |
| 爱吃 | Token，按个数吃，不按斤 |
| 特技 | 喷水、深度思考、长上下文 |
| 弱点 | 服务器一繁忙就头晕 |

## 设计要点

- **圆滚滚的身体**：大肥鱼，名副其实。
- **翘起的双叶尾巴**：取自 DeepSeek logo 的鲸尾，一片朝上、一片朝右。
- **白色月牙肚皮**：取自 logo 身上的白色弧线，外面留一圈蓝边。
- **斜眼差分**：logo 同款眼神。

## 表情差分

| key | 名称 | 台词 | 桌宠里的用途（暂定） |
| --- | --- | --- | --- |
| `idle` | 待机 | 今天也要游来游去～ | 默认状态 |
| `hello` | 打招呼 | 你好呀！我是大肥鱼！ | 启动、鼠标悬停 |
| `happy` | 开心 | 嘿嘿，被夸了～ | 被点击、摸头 |
| `think` | 深度思考 | 嗯……让我想想。 | 等待回复 |
| `busy` | 服务器繁忙 | 服务器繁忙，请稍后再试。 | 出错、断网 |
| `sleep` | 睡觉 | Zzz…… | 长时间无操作 |
| `sideeye` | 斜眼 | ……你认真的？ | 被连续戳 |
| `surprised` | 惊讶 | 诶？！ | 被拖起来 |
| `eat` | 吃 Token | 嗷呜，Token 真好吃！ | 喂食互动 |

## 文件

| 路径 | 内容 |
| --- | --- |
| `fatfish.js` | 角色 SVG 生成器，之后桌宠程序会直接用它。尾巴、身体、鳍、脸、特效各在一个分组（`tail` / `body` / `fin` / `face` / `fx`），方便做摇尾巴、眨眼、上下浮动之类的动画 |
| `svg/` | 每个表情一张 SVG，512×512，透明背景 |
| `png/` | 同样的内容导出成 PNG |
| `hero.png` | 主立绘，1400×2240 |
| `character-sheet.png` | 角色设定图，1800×1200 |
| `sheet.mjs`、`build.mjs` | 设定图排版和出图脚本 |

## 重新出图

```bash
npm install
npx playwright install chromium   # 本机没有 Chromium 时才需要
npm run art
```
