# DeepSeek-Pet · 立绘与状态图

![角色设定图](character-sheet.png)

立绘是用 ChatGPT 按 [`prompts.md`](prompts.md) 生成的高清透明 PNG，每个状态一张，1024×1536，风格对齐参考图。这里再做两件事：把各张统一到同一身高、按脚底对齐，然后把梗文字写进空白的牌子和思考泡泡。

## 角色档案

| 项目 | 设定 |
| --- | --- |
| 名字 | DeepSeek-Pet（DeepSeek 娘） |
| 外号 | 大肥鱼（本人坚决不认） |
| 物种 | 鲸鱼娘 · 体重 671B |
| 干活 | MoE，每次只用 37B 的力气 |
| 出身 | 杭州 · 深度求索 |
| 生日 | 1 月 20 日（R1 发布日） |
| 口头禅 | 「嗯，用户说……」 |
| 记性 | 128K 上下文，记仇也记得清 |
| 爱好 | 开源（MIT 协议）、便宜大碗 |
| 弱点 | 人一多就「服务器繁忙」 |

## 用到的梗

- **服务器繁忙**：「服务器繁忙，请稍后再试。」写在她举着的牌子上。
- **深度思考**：思考泡泡里是 R1 思考过程的经典开头「嗯，用户说……」；桌宠思考时还会挂上「已深度思考（用时 N 秒）」。
- **官网问候**：打招呼台词用的是首页那句「我是 DeepSeek，很高兴见到你！」。
- **aha moment**：R1 论文里模型自己喊「等等」的顿悟时刻，做成了「顿悟」状态。
- **参数和上下文**：671B 总参数、37B 激活（MoE）、128K 上下文，写进了档案和「无语」的台词。
- **便宜又开源**：MIT 协议开源、价格便宜、夜间错峰优惠，分给了「开源啦」「吃 Token」「睡觉」三个状态的台词。
- **大肥鱼**：成了她不肯承认的外号；围裙上绣着一只小鲸鱼。

## 状态

| key | 名称 | 台词 | 桌宠里什么时候出现 |
| --- | --- | --- | --- |
| `hello` | 打招呼 | 我是 DeepSeek，很高兴见到你！ | 启动、挥手打招呼 |
| `idle` | 待机 | 有什么可以帮你的吗？ | 平时、溜达、伸懒腰、东张西望、假装点任务栏、看时间 |
| `think` | 深度思考 | 嗯，用户说…… | 闲着时自己想事情 |
| `busy` | 服务器繁忙 | 服务器繁忙，请稍后再试。 | 连点 5 下、自己急得冒汗 |
| `happy` | 开源啦 | 全部开源，MIT 协议，随便用～ | 单击、跳舞、蹦跳 |
| `aha` | 顿悟 | 等等，我好像悟了！ | 想完事情、被拎起来、被叫醒、有新版本 |
| `eat` | 吃 Token | Token 便宜又大碗，嗷呜！ | 双击、自己吃 Token |
| `sleep` | 睡觉 | 夜间错峰优惠中……zzz | 一阵子没人理 |
| `sideeye` | 无语 | ……这题问过 128K 遍了。 | 连点 3 下 |

每个状态还有好几句备选台词，她做的各种事（溜达、小跑、掉头、去隔壁屏幕、假装点任务栏、看时间、跳舞、被拎起来、放下、深夜、早上、有新版本……）也各有台词，都在 `states.mjs` 的台词本里。

## 文件

| 路径 | 内容 |
| --- | --- |
| `raw/hd/` | ChatGPT 生成的原图，每个状态一张 |
| `cut/` | 统一身高、按脚底对齐后的图，908×1337，透明背景 |
| `png/` | 最终状态图：在 `cut/` 的基础上写好了牌子和泡泡里的字，桌宠直接用 |
| `character-sheet.png` | 角色设定图，1800×1200 |
| `states.mjs` | 台词本（各状态和各种事的台词）、状态名，以及要写的字、图标取景的位置，和各张图上会自己动的部位（眨的眼睛、挥的手、啃的金币） |
| `prompts.md` | AI 绘图提示词 |
| `cutout.py` | 对齐脚本；白底的图也能先抠图再对齐 |
| `build.mjs`、`sheet.mjs` | 写字、做图标、排设定图的脚本 |

## 重新出图

```bash
# 1. 统一身高、对齐（需要 Python）
pip install onnxruntime numpy pillow scipy
python art/cutout.py art/raw/hd/*.png --normalize --out art/cut

# 2. 写字、图标、设定图（需要 Node）
npm install
npx playwright install chromium   # 本机没有 Chromium 时才需要
npm run art
```

`--normalize` 会把各张图缩放到同一身高（最高 1300 像素）。换了新图以后，牌子、泡泡和脸的位置会变，改 `states.mjs` 里的 `ART_CANVAS`、`OVERLAYS`、`ICONS` 和 `RIGS` 就行；如果连身材、姿势都变了，`app/puppet.js` 里量好的脖子、腰、腿、尾巴的位置也要跟着改。
